name: research-planning
description: Search enabled vendor documentation tools and synthesize a concise, sourced answer. Activate before every substantive Cloudflare or AWS product documentation request, including behavior, architecture, comparison, migration, troubleshooting, security, and best practices.
---

Follow this procedure:

1. Identify the vendor or vendors in scope and use only their enabled MCP tools.
2. Start with one focused search containing the exact product, feature, API, error, or behavior being investigated.
3. For independent comparisons, search the relevant vendors in the same tool batch when possible.
4. Refine only when the first result leaves a material evidence gap; never repeat a substantially similar query.
5. Use at most two searches for a direct question and at most two per vendor for a comparison unless the user explicitly requests exhaustive research.
6. Stop as soon as the question is supported and reconcile conflicts using the most specific current source.
7. Verify that every cited page title and URL directly support the adjacent claim.
8. Answer directly, cite official links, and label recommendations, uncertainty, or missing evidence.

Read `SOURCE_POLICY.md` when the request involves comparisons, security, architecture, or best practices.
